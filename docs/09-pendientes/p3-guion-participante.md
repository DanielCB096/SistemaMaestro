# Prueba de uso — SistemaTienda

**Para:** persona que usará el sistema en una tienda real.  
**Tiempo estimado:** 30–45 minutos.  
**No hay respuestas incorrectas:** si algo te confunde o falla, eso es lo que queremos descubrir.

## Antes de empezar

- Usa la computadora con el acceso directo **“Prueba P3 - SistemaTienda”**.
- No uses datos reales de clientes ni ventas reales.
- Si algo no está claro, anótalo y sigue como puedas. No pidas ayuda hasta terminar.

| Dato | Valor |

| Nombre de la tienda | Abarrotes La Esquina |

## Tareas

Marca cada tarea cuando la termines. Si algo falla, escribe qué pasó.

- [ ] **1. Abre la app y configura la tienda.** Usa los datos de la tabla. Elige el PIN 2468.
- [ ] **2. Inicia sesión** con el PIN que acabas de crear.
- [ ] **3. Da de alta el producto** “Refresco 600 ml” con el código, costo, precio y stock de la tabla.
- [ ] **4. Vende 2 refrescos en efectivo.** El cliente paga con $50. Revisa el cambio.
- [ ] **5. Consulta la caja y cierra el corte.** Cuenta el efectivo. Deberías tener $230.00 (fondo de $200 + venta de $30).
- [ ] **6. Crea un respaldo y expórtalo.** Anota dónde quedó el archivo.
- [ ] **7. Restaura ese mismo respaldo.** La app se cerrará. Vuelve a abrirla, inicia sesión y confirma que la tienda y el producto siguen ahí.
- [ ] **8. Cierra sesión.**
