## Reglas

- Una decisión por ADR.
- Estado: propuesto, aprobado, rechazado o reemplazado.
- Toda decisión aprobada debe tener evidencia y consecuencias.
- Si cambia una decisión, se crea un ADR nuevo que reemplaza al anterior; no se edita el histórico.
